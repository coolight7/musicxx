# 插件
- 除去必要的基础核心功能之外，拟声把大部分扩展功能放在了`插件`里。
- 拟声支持功能插件化，可以按需启用功能，降低性能负担
- 从 `v0.90.0` 开始，拟声支持了`外部插件框架`，用户可以自定义开发、安装插件，实现自定义功能，且完善了 AI全自动开发 支持，不了解开发的用户也可以借助 AI 直接许愿！
- 也就是说，目前拟声内置两种插件：
    - **内置插件**; 在打包拟声时就已经内置，在插件页面安装、卸载控制该功能模块是否启用和配置，内置插件框架不支持用户自定义开发，仅作为控制功能模块启用/禁用/配置管理
    - **外部插件**; 
        - 支持自定义安装 动态库插件、JS插件、加载shader着色器，其功能十分强大，可实现 自定义播放页面背景渲染、自定义字体、控制拟声播放暂停切歌等各种操作。其中，**动态库插件**可由 C/C++ 等语言开发，性能远超 JS 脚本插件，但开发难度也比较高，且其权限很大，不受拟声管控，安装时应当确认来源可信。
        - 由我们开发 [agentxx](https://github.com/coolight7/agentxx) 项目时意外发展而来，最初在 agentxx 中开发异步动态库插件框架后，发现非常好用，且可以迁移到其他项目，因此在拟声这试水，目前效果不错
